# ヴェール（PC・完全オフライン）

イラスト / 実写の局部を検出してモザイクします。  
画像もモデルも **このPCから出ません**。

## いちどだけ準備

Python 3.10 以上が必要です。

**Windows:** `run.bat` をダブルクリック。  
初回だけ `pip` がライブラリを取りにいくのでネットが要ります。2回目からオフラインで動きます。

または:

```bash
cd veil_offline
python -m pip install -r requirements.txt
python app.py
```

ブラウザで `http://127.0.0.1:8080` が開きます。

## 使い方

1. 検出モデルを選ぶ（イラスト / 実写）
2. どれかで渡す
   - 画像を複数ドロップ
   - **フォルダを選ぶ**
   - **フォルダのパスを貼る**（エクスプローラのアドレスバー）  
     例: `C:\Pictures\batch` / `/Users/you/pics`
3. 「モザイクを実行」
4. 結果は `入力フォルダ/_mosaic/` に保存。ZIP でも落とせます

上限 200 枚。1枚ずつ処理します。元画像は上書きしません。

## オフライン

- モデルは `models/` に同梱（Hugging Face 等へ取りにいきません）
- Gradio の共有リンクは使いません
- 初回の `pip install` 以外、ネットは不要です
