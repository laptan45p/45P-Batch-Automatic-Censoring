# ヴェール 輪郭対応更新

## 更新方法

このZIPの `veil_offline` フォルダの中身を、現在使用しているフォルダに上書きしてください。
既存の `models` と `.venv` はそのまま使います。検出モデルはこの差し替えZIPに含まれていません。
`run.bat` を実行すると追加依存のOpenCVが導入されます（初回のみネットが必要）。

## 追加機能

- 読み直しボタンで選択情報がない場合に例外が出る問題を修正しました。処理結果があれば最初の画像を開き、処理前なら画面へ案内を表示します。
- Canvas版の保存ボタンでSliderに文字列が渡るエラーを修正しました。クリック時のJavaScriptによる引数置換を削除し、描画終了時に選択PNGを通常の入力欄へ同期する方式に統一しました。
- Canvasに拡大・縮小・全体表示・原寸表示を追加しました。＋／−ボタンまたはCtrl＋ホイールで倍率を変更できます。拡大した画像の移動はスクロールバーを使います。描画座標は表示倍率から元画像の座標へ変換します。
- 手動描画欄をHTML Canvas方式へ置き換えました。左ボタンを押したまま移動すると、線をCanvasに直接描画します。描画中の表示にサーバー応答やGradioの画像エディターは使用しません。
  - ペン・消しゴム・太さ（画像上のpx）・ひとつ戻す・選択範囲クリアを用意しました。ペンのピンク色は選択表示だけで、出力画像に入りません。
  - 「編集画像を閉じる」で選択状態を解除し、同じ処理結果も再選択できます。「最後に選んだ画像を読み直す」も使用できます。
  - 「選択範囲をクリア」は描いた範囲だけを消します。保存済みモザイクを消す機能ではありません。
  - 以前のGradio内部JavaScriptへの互換修正は呼び出しません。起動後、ブラウザでCtrl+F5を押して更新してください。
- 手動修正：自動処理後、結果の画像をクリックして選び、ブラシで漏れた場所を囲んで再検出できます。
  - 「囲んだ線の内側も処理する」を有効にすると閉じた輪郭の内側も埋めます。線が開いている場合は内側が埋まりません。
  - 消しゴムはブラシの選択範囲を消します。既存のモザイクを取り除く機能ではありません。
  - 初期設定は「範囲内を再検出」。囲んだ場所を元画像から切り出し、検出AIに入力します。離れた複数の選択範囲は個別に切り出します。周辺の文脈も少し含めますが、モザイク追加は指定範囲内だけです。
  - 再検出は自動処理時の検出モデル・対象・信頼度・範囲拡大・形状・輪郭設定を再利用します。輪郭モードなら簡易方式またはSAMも使用します。種類・粗さは左側の現在の設定を使用します。
  - 検出なし、または追加する処理画素がない場合は画像を変更せず、選択範囲を残して理由を表示します。断面図を必ず検出できる保証はありません。
  - 「範囲全体にかける」に切り替えるとAIを使わず指定範囲を処理できます。自動でこの方法へ切り替わることはありません。
  - 手動修正後はギャラリー・比較画像・ZIP・指定したローカル保存先を更新します。入力画像は変更しません。
  - 保存後はブラシの選択をクリアします。同じ画像に続けて追加修正できます。
  - 検出件数の一覧は自動検出の記録です。手動修正は手動修正欄のメッセージで確認します。
- 形状「輪郭」：抽出したマスクの内側にモザイクをかけます。
- 簡易輪郭：OpenCV GrabCutによる色の差を使った抽出。追加AIモデルは不要です。
- SAM輪郭：既存検出器の範囲をSAMのボックス入力に渡して抽出します。
- 輪郭の外側の余白：0〜64px。初期値6px。穴は埋めて処理します。
- 周辺の拡大再検出：検出済み範囲を切り出し、再推論します。見逃した箇所を新規発見する機能ではありません。
- 輪郭が空、小さすぎる、過大などの場合は矩形へ切り替え、結果一覧に理由を表示。
- 別クラス同士の検出を消してしまわないよう、重複除去をクラス別に修正。

「範囲の拡大」は輪郭抽出時の処理範囲と失敗時の矩形範囲です。
輪郭そのものを広げるには「輪郭の外側の余白」を使ってください。
検出枠の表示は従来どおり矩形のガイドで、マスクの輪郭表示ではありません。

## SAMの準備（任意）

この更新はSAM 2ではなく、Windowsでも組み込みやすいオリジナルSAMを使用します。
簡易方式ではこれらの準備は不要です。

1. Gitを導入済みの環境で `install_sam.bat` を実行します。既存の `.venv` に追加し、公式vit_bモデルも `models` に自動ダウンロードします（約375MB）。
2. SAMモデルは `models` フォルダに固定します。パスの入力は不要です。導入済みのモデルは検証して再利用し、不完全なダウンロードは削除します。手動で用意する場合は次の公式ファイルを使用できます。
   - 推奨の軽量モデル：`sam_vit_b_01ec64.pth`
   - https://dl.fbaipublicfiles.com/segment_anything/sam_vit_b_01ec64.pth
   - vit_l（約1.2GB）：https://dl.fbaipublicfiles.com/segment_anything/sam_vit_l_0b3195.pth
   - vit_h（約2.4GB）：https://dl.fbaipublicfiles.com/segment_anything/sam_vit_h_4b8939.pth
   - 公式説明：https://github.com/facebookresearch/segment-anything
3. 輪郭抽出方法で「SAM（追加モデル）」を選びます。
4. モデル種類は `vit_b` を選択します。選択した種類から対応するファイルを自動で読み込みます。
   手動で入れたvit_lまたはvit_hを使う場合は、対応する種類を選びます。ファイル名は変更しないでください。
   - `vit_b`: `models/sam_vit_b_01ec64.pth`（自動導入）
   - `vit_l`: `models/sam_vit_l_0b3195.pth`（手動導入）
   - `vit_h`: `models/sam_vit_h_4b8939.pth`（手動導入）
5. CPUでも動作します。GPUを使うにはCUDA対応PyTorchが必要です。
   インストール方法は https://pytorch.org/get-started/locally/ で環境に合うものを確認してください。

モデルはローカルから読み込み、画像を外部に送信しません。
SAMは画像ごとに読み込みます。一括処理では速度よりメモリ解放を優先した実装です。

## 精度と検証範囲

色による簡易抽出もSAMも、対象部位を必ず正しく切り抜ける保証はありません。
同じ肌色の周囲、重なり、背景と色が近い画像ではずれることがあります。
矩形への切り替え判定は形状の妥当性検査であり、隠すべき画素の完全性は保証しません。
重要な出力は比較画像で確認し、必要なら矩形で処理してください。

同梱テストは人工画像で輪郭・余白・穴埋め・失敗時処理・再検出・重複除去を確認します。
25項目の自動テストとGradio画面の構築を確認しました。元画像からの再検出入力、範囲外と既存処理画素の保持、検出なしの場合の画像・選択保持をテストしています。Gradioのprocess_apiで実際のState・Radio・Slider入力チェックから保存コールバックとZIP更新まで通ることを確認しました。Canvasの選択PNGから修正保存、ZIP更新、ローカル保存先への反映まで確認済みです。DOMと実際のCanvas描画を使用してマウスイベントを再現し、ボタンを離す前のペン表示、表示縮尺に応じた座標変換、消しゴムのリアルタイム表示、ボタンを離したときの選択PNG送信、範囲クリアを確認しました。拡大・縮小・全体表示・原寸・Ctrl＋ホイールも操作再現テスト済みです。実ブラウザ操作とWindows実機は未検証です。
実際の検出モデルとSAMチェックポイントによる精度評価、WindowsとGPUの実機検証は未実施です。
