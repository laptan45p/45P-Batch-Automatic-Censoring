# ヴェール 1.0.0

2026-09-20

イラストや実写の局部を見つけてモザイクをかけるアプリです。  
Windows のパソコンで、**ネットにつなげずに**使えます。処理する画像も学習モデルも、外には出ません。

## できること

- **イラスト**と**実写**で、検出の仕方を切り替えられます
  - イラスト：女性器・男性器・胸部
  - 実写：上記に加えて肛門・臀部
- まとめて処理できます
  - 画像を何枚でもドロップ
  - フォルダを選ぶ
  - エクスプローラのアドレスを貼り付ける
- 結果は `入力フォルダ/_mosaic/` に保存します。元のファイルはいじりません
- 処理の前後を、スライダーで重ねて比べられます
- モザイクはピクセルかぼかし、形は楕円か矩形。範囲・粗さ・厳しさも調整できます
- 終わった画像は ZIP でも落とせます
- 一度に扱えるのは 200 枚まで。すでに出した `_mosaic` フォルダは読み直しません

## 必要なもの

- Windows 10 / 11（`run.bat`）。macOS や Linux なら `run.sh`
- Python 3.10 以上。入れるときは **Add python.exe to PATH** に必ずチェック
- 最初の一回だけネット（仮想環境の作成とライブラリの導入）。二回目からはオフライン
- GPU は不要です。CPU だけで動きます

## ZIP に入っているもの

| ファイル | 役割 |
|---|---|
| `run.bat` / `起動.bat` | Windows 用。ダブルクリックで起動します |
| `run.sh` | macOS / Linux 用 |
| `app.py` / `engine.py` | 画面と、検出・モザイクの本体 |
| `models/` | イラスト用・実写用のモデル |
| `requirements.txt` | 必要なライブラリの一覧 |
| `使い方.txt` | 最短の手順 |

## 使い方

1. ZIP を解凍する
2. `run.bat` をダブルクリックする
3. 初回だけ、このフォルダの中に `.venv` ができます。ComfyUI など、ほかの Python には触れません
4. ブラウザが開きます。終えるときは、黒い窓を閉じてください

入れ直したいときは、`.venv` フォルダを消してからもう一度 `run.bat` を実行します。

## 1.0.0 で変わったこと

- ブラウザの中だけで動かす形から、パソコンに入れてオフラインで使う形にしました
- イラスト向けの検出を足しました
- フォルダごとまとめて処理し、`_mosaic` に保存するようにしました
- Windows の `run.bat` が文字化けしないようにしました
- ライブラリはシステムの Python ではなく、このフォルダの仮想環境（`.venv`）に入れるようにしました
- 見た目は Gradio 標準の Base（青いアクセント）に、暗い背景を載せています
- 比較スライダーの画像がずれていたのを直しました。高さは以前のおよそ 75% です
- 出力済みの `_mosaic` を、もう一度取り込まないようにしました

## いまの制限

- 検出は完璧ではありません。構図や塗りによっては、見逃したり余計なところを拾ったりします
- 画像は一枚ずつ順番に処理します。同時には回りません
- 動画には対応していません
- Python が入っていない、または PATH が通っていないと起動しません
- 最初のライブラリ導入だけ、ネットが必要です

## 使っているモデル

- 実写：NudeNet ONNX（320n）
- イラスト：anime-censor-n（YOLOv8 系）
- アプリ本体のソースは、この ZIP に入っています
